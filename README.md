# CS255
DriversPass Project
This repository contains my completed work for CS 255: System Analysis and Design. The project includes a Business Requirements Document (BRD) and a System Design Document (SDD) for the DriverPass scheduling system.

## Contents
- **BRD/** – Business Requirements Document  
- **SDD/** – System Design Document  

## Project Summary
DriverPass is a scheduling and training system designed to help students prepare for their driving exam. The project includes business requirements, system architecture, UML diagrams, database design, and security considerations.

- UML  
- System Analysis  
- Requirements Engineering  
- System Design
